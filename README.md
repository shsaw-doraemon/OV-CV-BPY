# OV-CV-BPY
A Modular Pipeline for Reconstructing Primitive Character Shapes from Orthogonal-View Images.
# Pre Conditions
1. VS Code: https://code.visualstudio.com/

    1.1 Python Extension or Self-Installed Python
    1.2 Blender Developer Extenstion    
        Extension Identifier: jacqueslucke.blender-development

2. Blender executable: https://www.blender.org/download/

# Steps to use the modules

## 1. Resize Orthogonal Images
Module path: ov-cv-bpy modules/ortho_img_input_handler.py
    documentation of how to run is available in the module
### Steps to run this module:
1. Install Streamlit and Pillow if not already installed:
    pip install streamlit pillow
2. Run the Streamlit app:
    streamlit run upload_image.py
3. The images will be saved in \data\input\uploaded_image

Tips for preparing orthogonal view images with clean background: 
    1. can remove the background of the image using online tool (image preprocessing)
    2. example tool: https://www.photopea.com/

## 2. 2D Mesh Polygon Mask Segmentation using External Tool
Tool: CVAT:  https://www.cvat.ai/
Method: semi-auto segmentation using AI tool with model SAM 2
Annotation Preparation Guideline:
    1. set 2 attributes: "name" and "view"
    2. "name" = <name of mesh or character part>
    3. "view" = <name of the current image. space: {front, left, back, right}>
    4. Export the annotations in COCO 1.0 Format
    5. Download and put the annotation JSON file into path: \data\json

## 3. 3D Features Reconstruction
Run \ov-cv-bpy modules\3d_feature_recon.py

## 4. BPY Mesh Generation
Run \ov-cv-bpy modules\mesh_gen.py
### Steps to run:
1. click the search bar at the top of VS Code IDE, 
   click show and run commmand >
   search "Blender: Start", 
   select the blender executable path 
   (e.g. C:\Program Files\Blender Foundation\Blender 4.4\blender.exe)
2. once blender started, Click "Blender: Run Script"

### Access the Output
The mesh will be generated in \blender\Blend files
